# 🎓 Enroll Pro: Student Course Enrollment System

A modern, web-based enrollment management system designed for administrators to manage students, instructors, and course registrations with ease. This project features a high-end "Glassmorphism" UI and real-time data synchronization with a Strapi backend.

## 🚀 Technologies Used
* **Frontend:** Nuxt 4 (Vue 3 Composition API)
* **UI Framework:** Vuetify 3
* **Backend:** Strapi v5 (Headless CMS)
* **Database:** SQLite / PostgreSQL

## ✨ Key System Features
* **Interactive Dashboard:** Displays real-time statistics for registered students, active courses, faculty, and total enrollments.
* **Recent Activity Log:** Tracks the latest 5 enrollment transactions automatically to provide summary information.
* **Full CRUD Modules:** Implemented complete Create, Read, Update, and Delete functionality for Students, Courses, Instructors, and Enrollments.
* **Advanced Enrollment Tracking:** Features a dynamic status management system with color-coded indicators for `Pending`, `Enrolled`, `Dropped`, and `Completed`.
* **Detailed Student Profiles:** Allows administrators to view comprehensive student records including their full history of enrolled courses.
